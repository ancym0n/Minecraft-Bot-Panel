Privacy Policy

Last updated:

1. The Short Version

MCBP runs on your computer. There are no MCBP servers, no accounts, no analytics, and nothing gets sent to me. The only things that go over the internet are the connections listed below, and they're all things the app needs to actually work.

2. What Gets Saved on Your Computer

  • Microsoft logins: when you sign in, Mineflayer's login library caches your tokens so you don't need a new device code every time. MCBP also keeps a small list of accounts you've used (email or name, Minecraft name, UUID) so you can pick them again. You can remove an account from the login screen and its cached tokens go with it.
  • Settings: the last Minecraft version you picked, your script options, AI settings, and any update you chose to skip.
  • Session logs: each session writes a Markdown log (what you clicked, chat, game events) into the app's logs folder, so you can look back at what happened or attach it to a bug report. They never leave your computer unless you send them yourself.
  • Downloads: the Mineflayer runtime, the Mineflayer docs for Script Studio, and, if you set up the AI, Ollama and its models.
  • Your files: anything in custom/scripts/ and custom/theme.css.

3. Network Connections

  • Minecraft servers: when you click Connect, the bot connects straight to the server you typed in.
  • Microsoft & Xbox Live: only in Microsoft mode, to log you in.
  • npm (registry.npmjs.org): on launch and when you click Sync, to check for and download newer mineflayer, minecraft-data and mineflayer-pathfinder versions.
  • GitHub: to check for new MCBP releases (updates are never forced) and to download the Mineflayer docs used in Script Studio.
  • Ollama: only if you use the AI. Setup downloads Ollama and the model you pick from Ollama's servers.
  • Google Fonts: the app loads the Nunito and Poppins fonts, so Google sees your IP address when it opens.

4. The AI Stays Local

ChatAI, AIAgent and the Script Studio generator all talk to Ollama running on your own machine (127.0.0.1). Chat messages, game info and prompts are not sent to any cloud AI service. Keep in mind that whatever the bot says in chat is, of course, seen by the Minecraft server and the players on it.

5. Custom Scripts

Scripts in custom/scripts/ (including ones made in Studio) run on your computer with full Node.js access. Same goes for code the AIAgent writes if you turn on Allow Code. Only run scripts you wrote yourself or got from someone you trust, and only give Allow Code to players you trust.

6. This Website

No cookies, no analytics. Your browser loads fonts from Google Fonts, and the page asks the GitHub API, shields.io and raw GitHub content for the latest release files, download and star counts, and the supported Minecraft versions, so those services can see your IP address. The Download Manager caches release info in your browser's local storage, and the "last updated" date above is cached in session storage until you close the tab.

7. In Short

  • Nothing collected or sold: no data from the app is collected, sold or shared with anyone.
  • No tracking: no analytics, no ads, nothing running in the background phoning home.
  • You're in control: everything is stored in files on your device, and the full source code is on GitHub.

8. Changes to This Policy

If the app starts handling data differently, this page gets updated. The date at the top shows when it last changed.
