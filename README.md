[![Website](https://img.shields.io/badge/Website-ancymon.dev-9171f8?labelColor=efeaff&logo=globe&logoColor=white)](https://ancymon.dev/Minecraft-Bot-Panel/)

This branch is the website for [Minecraft Bot Panel](https://github.com/ancym0n/Minecraft-Bot-Panel). It's plain HTML, CSS and a bit of JS, no build step. Open `index.html` or serve the folder with anything and you're good.

![Banner](src/img/mcbp-title.svg)

## Pages

- [Home](https://ancymon.dev/Minecraft-Bot-Panel): download button and FAQ
- [Docs](https://ancymon.dev/Minecraft-Bot-Panel/docs): install, all 26 scripts, the local AI, Script Studio, custom scripts and themes
- [Privacy](https://ancymon.dev/Minecraft-Bot-Panel/privacy): what the app stores and what it connects to

The Download button pulls the latest release from the GitHub API and picks the right file for your system (Windows, deb, rpm, pacman, AppImage, tar.gz or macOS). If GitHub is down or rate-limited, it falls back to a cached copy or a built-in list.
